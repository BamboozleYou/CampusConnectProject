# CampusConnect (Earlier Team Version)

> **The current app is [CC_CampusConnect](https://github.com/BamboozleYou/CC_CampusConnect).** This repo is kept to show the app's early development.

An early Kotlin version of a campus events app for BMSCE, with the home screen and event details built on feature branches. It doesn't use Firebase; that came in the current version.

## What's here

| File | Purpose |
|---|---|
| `MainActivity.kt` | Home screen |
| `EventDetailsActivity.kt` | Event details page |
| `EventAdapter.kt`, `NewsAdapter.kt` | List rendering |
| `Event.kt` | Event data model |

## Run it

Open the project in Android Studio and run it on an emulator or device.
